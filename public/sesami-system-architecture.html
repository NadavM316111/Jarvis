Sesami System Architecture

Physical Layer

The Sesami bear houses a Raspberry Pi Zero 2 W with integrated microphone array, premium speaker, and RFID reader for activity cards.

Cloud Processing

AWS-hosted services handle voice cloning, speech-to-text, natural language processing, and activity recommendation algorithms.

Data Security

End-to-end encryption protects all voice data and child information. COPPA compliant with parental consent requirements.
